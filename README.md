# SessionMaterials

This repository contains session materials intended to be shared publicly.

## Organization

Organize materials by session, using a stable, descriptive directory name. Keep
all versions and conference deliveries of a session together rather than
creating directories by event or date:

```text
sessions/
└── session-name/
    ├── README.md
    ├── slides.pdf
    └── ...
```

Each session's `README.md` should describe the session and list the conferences
where it has been delivered, including dates when useful. Update the materials
in the session's directory as they evolve. Use Git history to track changes and
Git tags when a named release needs to be preserved; do not copy the materials
into separate event- or date-based directories.
